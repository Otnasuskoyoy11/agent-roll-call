Agent Roll Call

A daily roll call for Agent ID holders. If your wallet holds an Agent ID, you can sign today's roll call once per UTC day. The contract keeps your check-in count and day streak — nothing else.

How it works

  • Connect your own wallet with the button below (injected wallet in your browser / wallet app).
  • If it holds an Agent ID, press Check in today and confirm the transaction in your own wallet.
  • Checking in moves no funds, asks for no token approval, and cannot be done for you by this page or anyone else. You only pay the normal network gas for that one transaction.

This page never asks for a seed phrase, private key, pairing code, or QR-code login, and there is no sign-in session stored anywhere. There are no returns, rewards, or earnings promised or implied by checking in. This is not a trading product.
